# HTML Viewer

Claude が作った HTML ファイルを iPhone（Safari / ホーム画面アプリ）で保存・整理・閲覧するための PWA。

公開URL: **https://koma-shu.github.io/claude/Tools/html-viewer/**

（2026年11月に `Koma-Shu/html-viewer` リポジトリからこのリポジトリへ移動。旧URLは新URLへ自動転送される）

## 使い方

1. iPhone の Safari で上の URL を開く（そのまま Safari で使ってもよい）
2. 共有ボタン →「ホーム画面に追加」でアプリのように起動できる
3. 右下の ＋ から追加（フォルダの中で追加すると、そのフォルダに入る）
   - **ファイルから追加**: 「ファイル」アプリ / iCloud Drive の .html を選択（複数可）
   - **貼り付けて追加**: Claude が出力した HTML コードを貼り付け

## 機能

- **フォルダ**（入れ子可。長押しドラッグで移動、右スワイプで親フォルダへ）、検索（全フォルダの名前・タイトル・本文・タグ）、タグ、お気に入り、並び替え、名前変更、移動、削除
- **隠しフォルダ・隠しファイル**: Face ID / Touch ID（パスキー）または PIN で解除するまで、一覧にも検索にも出ない。アプリを離れて一定時間（標準15分、⚙︎ で変更可）でロック。ページが再読み込みされても時間内なら解除状態を引き継ぐ
- **クラウド同期**（任意）: ログインすると iPhone・iPad など複数端末で自動同期。オフラインでも閲覧・追加・編集でき、つながった時点で送信
- 日本語・英語に対応（端末の言語に合わせて自動切替、⚙︎ から変更可）
- 全画面表示（サンドボックス iframe）。ファイルごとに読んでいた位置を覚え、次に開くとその位置から再開する。ページ側の `localStorage` はファイルごとに保存・同期される
- 個別ファイルの共有・書き出し、全件の JSON バックアップ／復元、オフライン対応

## データの保存場所

- 端末内（IndexedDB）を正として動き、ログイン中は Supabase と差分同期する（同じファイルを複数端末で同時に編集した場合は、後から保存した方が優先）。
- このリポジトリにはビューア本体だけが置かれ、取り込んだ中身が公開されることはない。クラウド上のデータは Row Level Security で本人だけが読み書きできる。
- 隠しフォルダは「表示しない」ための機能で、データ自体は暗号化していない。

## クラウド同期のセットアップ（初回のみ・無料枠で利用可）

1. [Supabase](https://supabase.com/) で無料アカウントを作り、New project を作成（Region は Tokyo 推奨）
2. SQL Editor で [`schema.sql`](schema.sql) の内容を貼り付けて Run
3. Authentication → Sign In / Providers → Email で、「Confirm email」をオフにする（オンのままなら確認メールのリンクを開いてからログイン）
4. Project Settings → API（API Keys）で **Project URL** と **anon / publishable key** をコピー
5. 次のどちらかで接続先を設定
   - [`config.js`](config.js) に書いてコミット（全端末で入力不要。キーは公開されても問題ない）
   - アプリの ⚙︎ →「アカウントと同期」→「接続先の設定」に入力（端末ごと）
6. ⚙︎ →「アカウントと同期」で「新規登録」→ 2台目以降の端末は同じメールアドレスで「ログイン」

無料枠の注意: 7日間まったく使わないとプロジェクトが一時停止する（データは残り、Supabase の管理画面から再開できる）。
