# HTML Viewer

Claude が作った HTML ファイルを iPhone（Safari / ホーム画面アプリ）で保存・整理・閲覧するための PWA。

公開URL: **https://koma-shu.github.io/html-viewer/**

## 使い方

1. iPhone の Safari で上の URL を開く（そのまま Safari で使ってもよい）
2. 共有ボタン →「ホーム画面に追加」でアプリのように起動できる
3. 右下の ＋ から追加
   - **ファイルから追加**: 「ファイル」アプリ / iCloud Drive の .html を選択（複数可）
   - **貼り付けて追加**: Claude が出力した HTML コードを貼り付け

## 機能

- 検索（名前・タイトル・本文・タグ）、タグ、お気に入り、並び替え、名前変更、削除
- 全画面表示（サンドボックス iframe）。ページ側の `localStorage` はファイルごとに保存され、次回も引き継がれる
- 個別ファイルの共有・書き出し（AirDrop・メール・「ファイル」に保存）
- 全件を JSON にバックアップ／復元
- オフライン対応

## データの保存場所と複数端末での利用

- 取り込んだ HTML は **その端末・そのブラウザの中（IndexedDB）だけ** に保存され、サーバーには送信されない。
  このリポジトリにはビューア本体のみが置かれ、取り込んだ中身が公開されることはない。
- ビューア自体は URL を開けばどの端末からでも使える（私用 iPhone・社用 iPhone・PC など）。
- 端末間でファイルを移すには、⚙︎ →「すべてをバックアップ」で JSON を書き出し、
  AirDrop / iCloud Drive などで渡して、もう一方の端末で「バックアップから復元」する。
- Safari とホーム画面アプリは保存領域が別々なので、どちらか一方に決めて使うのがおすすめ。
- Safari の「Webサイトデータを削除」やホーム画面アプリの削除でデータが消えるため、定期的にバックアップを取ること。

## 公開設定（初回のみ）

GitHub の Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存。
